This certification demonstrates comprehensive knowledge of network penetration testing, covering both wireless (WiFi) and wired network security assessment techniques. The course provides practical skills for identifying and exploiting network vulnerabilities.

## Course Overview

- **Instructors**: Zaid Sabih, iSecur1ty LLC
- **Platform**: Udemy Inc
- **Scope**: Network security assessment for WiFi and wired networks
- **Approach**: Hands-on training with real-world scenarios

## Learning Path

### Network Fundamentals
- Understanding network protocols and architectures
- Network traffic analysis and monitoring
- Basic network security concepts
- Setting up penetration testing environments

### Wired Network Security
- Network discovery and enumeration
- ARP spoofing and man-in-the-middle attacks
- Network protocol vulnerabilities
- Switch and router security assessment
- VLAN security and hopping techniques

### Wireless Network Security
- WiFi standards and security protocols
- Wireless network discovery and analysis
- WEP, WPA, and WPA2 cracking techniques
- Rogue access point attacks
- Wireless denial of service attacks

## Practical Skills

- Conducting comprehensive network security assessments
- Identifying network vulnerabilities and misconfigurations
- Implementing network attacks and penetration testing
- Analyzing network traffic and protocols
- Securing network infrastructure

## Tools and Technologies

- Wireshark for network analysis
- Aircrack-ng suite for WiFi security
- Nmap for network scanning
- Metasploit for network exploitation
- Various specialized network security tools

## Advanced Topics

- Network segmentation and isolation
- Intrusion detection and prevention systems
- Network monitoring and logging
- Advanced persistent threat techniques
- Industrial control system security

## Real-World Applications

- Enterprise network security assessment
- WiFi network security auditing
- IoT device security testing
- SCADA and industrial network security
- Cloud network security assessment
