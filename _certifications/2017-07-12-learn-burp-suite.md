This certification demonstrates expertise in using Burp Suite, the leading web application security testing platform. The course provides comprehensive knowledge of web application penetration testing using this powerful tool.

## Course Details

- **Instructor**: Geri Revay
- **Platform**: Udemy Inc
- **Focus**: Burp Suite for web application security testing
- **Level**: Intermediate to Advanced

## Core Learning Areas

### Burp Suite Fundamentals
- Installation and configuration
- Understanding the Burp Suite interface
- Proxy configuration and traffic interception
- Basic request/response manipulation

- Intruder for automated attacks
- Repeater for manual request testing
- Sequencer for randomness analysis
- Decoder for various encoding formats
- Comparer for response analysis

- HTTP request/response analysis
- Session management testing
- Authentication bypass techniques
- Input validation testing
- CSRF and XSS vulnerability detection
